\section[Introduction]{\textbf{Introduction}}
Global trade is increasingly defined by Logistics Friction a composite of temporal, financial, and physical delays at critical maritime chokepoints. Specifically in consideration of ongoing events we can consider the supply and logistics of Crude Oil, LNG and other petroleum products and by products which have been shown to be vulnerable. 

Large-scale enterprises employ sophisticated risk-modeling, Indian SMEs remain vulnerable to the "bullwhip effect" caused by sudden shifts in transit verification, insurance spikes, and port congestion. 

The Bullwhip Effect is a supply chain phenomenon where small fluctuations in consumer demand at the retail level cause progressively larger fluctuations at the wholesale, distributor, and manufacturer levels.

\subsection{Technical Concepts}
The work pulls together various high-level fields to build a sturdy supply-chain answer. This isn't just a simple tool, nor is it a basic database. It's something else entirely.
\begin{itemize}
    \item \textbf{Digital Twin:} A live, digital mirror of the actual logistics web. It tracks suppliers and ports alongside chokepoints or storage hubs. This isn't merely a map; it's a sandbox where we can throw disasters at the system to see what breaks. But the real value lies in the response testing. One could argue the data is the fuel, yet the engine is the simulation itself. It's a way to stay ahead of the curve.
    \item \textbf{Agentic Orchestration:} Customized LLM bots work through role-playing and prompt chains to tackle messy routing issues. But the real issue is how these independent units coordinate their specific tasks. This isn't just one model running scripts, but a collective of self-governing units that talk to each other - using specific personas - to find the best path forward. Naturally, they fix hard problems together.
    \item \textbf{Graph Theory \& Network Optimization:} We treat logistics lanes as directed graphs where \textbf{Dijkstra’s Algorithm} finds the most efficient routes. The software looks at every possible turn and connection within the digital map. By looking at dynamic weights (like how many days a shipment takes or the total landed costs) the system calculates paths that aren't just fast but actually cheap. And yet, data determine the direction.
    \item \textbf{Stochastic Inventory Management:} The \textbf{Chopra Safety Stock Equation} helps us account for the randomness in lead-time arrivals. It's a way to find the right balance between too much and too little. We calculate exactly how much buffer stock is needed to stop a stockout when a shock hits the supply chain - which isn't always easy to predict - ensuring the shelves stay full. This keeps the inventory levels safe.
\end{itemize}

\subsection{Technologies, Tools, and Frameworks}
The implementation leverages a modern, high-performance stack:
\begin{itemize}
    \item \textbf{Backend:} Python drives the core. FastAPI handles the heavy lifting for high-performance REST APIs and asynchronous tasks.
    \item \textbf{Orchestration Framework:} \textbf{CrewAI} defines specific roles and handles delegation across the entire fleet. The intelligence comes from \textbf{Gemini-Flash} LLMs connected through the Google AI Studio API.
    \item \textbf{Graph Modeling:} The \texttt{networkx} library constructs the directed graph representing the global logistics web. It tracks every node and edge to make sure routing remains mathematically sound.
    \item \textbf{Frontend:} React and Vite power a modern dashboard featuring a distinct glassmorphism aesthetic. Geospatial visualization happens through Leaflet, specifically the \texttt{leaflet} integration for routing.
\end{itemize}

\subsection{System Architecture and Working Principle}
The system is a reactive loop. Outside disruptions jumpstart the entire multi-stage response sequence. It isn't just a simple relay, nor is it a static database. The Friction Sentry starts by translating messy, unstructured signals into quantitative parameters - which isn't just data entry but a way to define the shock - before the Agentic Optimizer takes over. Specialized agents handle the heavy lifting. The Logistics Optimizer and Cost Analyst scout for better paths or check what's sitting in the warehouse. And yet, the final step remains the most vital. The Communicator Agent assembles a JSON payload to update the React dashboard with fresh routing and financial metrics (a critical hand-off) ensuring that the interface reflects the most current logistical reality without human intervention. Obviously, the goal is speed.

\subsection{Major Modules / Components}
The framework is divided into several specialized functional modules:
\begin{itemize}
    \item \textbf{Friction Sentry:} It grabs raw signal data. These data are converted into organized risk metrics. Often, these manifest as sudden insurance hikes or harbor bottlenecks.
    \item \textbf{Execution \& Routing Engine:} Managing the graph layout. This module handles the directed topology while executing routing logic for standard operations.
    \item \textbf{Dynamic Inventory Manager:} Monitoring current inventory. The tool calculates daily usage rates while managing simulated emergency restock orders.
    \item \textbf{Agentic Solver (CrewAI):} The system brain. This central hub houses the Logistics Optimizer, the Cost-Strategy Analyst, and the SME Communicator.
    \item \textbf{Digital Twin UI:} A React map app. This interactive geospatial tool displays the original paths alongside the improved ones. It presents financial data and operational stats through a series of clear performance cards.
\end{itemize}

\subsection{Real-World Applications}
Practical applications include dynamic rerouting of cargo to avoid high-risk maritime zones (e.g., bypassing the Red Sea via the Cape of Good Hope) and port congestion mitigation by automatically switching destination ports (e.g., from Nhava Sheva to Mundra). Most importantly, it empowers Indian SMEs with automated inventory protection strategies that are typically only accessible to large multinational corporations.

This effort links identifying shipping failures directly with automated fixes in the maritime sector. Global commerce isn't stable anymore; we need tools that act fast without human help. While predicting shocks is useful, it isn't enough - we need a setup that handles the actual recovery work to shield Indian SMEs from the messy fallout of global politics. The motivation for this work is some basic challenges observed in existing systems:
\begin{enumerate}

\end{enumerate}

By fixing these gaps, we turn a slow, reactive mess into a smart digital twin that keeps trade moving when things go south. Global trade needs resilience.

\subsection[Literature Survey]{\textbf{Literature Survey}}
The more established literature provides the conceptual and technological substrate for the newer agentic work. Digital twins are a central reference point: they have been applied to manage disruption risk in Industry 4.0 settings \cite{Ivanov2020}, and subsequent work has framed digital supply chain twins as a key direction for resilience research \cite{Nayal2022}. Reviews of digital twins in supply chains have emphasised visibility, agility, decision support, and integration with IoT, AI, and blockchain \cite{Nayal2022}. In parallel, the IoT literature has highlighted the operational promise of connected sensing in supply chain management \cite{Birkel2019}, while complementary work has examined the implementation risks of IoT adoption in these contexts \cite{BenDaya2019}.

The resilience literature further demonstrates why these technologies matter. Supply chain viability under COVID-19 has been extensively theorised \cite{Ivanov2021}, with parallel work examining disruptions arising from epidemic outbreaks more broadly \cite{Queiroz2020}. Subsequent research has extended this analysis to shortage-driven disruption scenarios \cite{Ivanov2022}. Sector-specific studies on food consumption have illustrated how disruptions alter demand patterns \cite{Chenarides2021}, while research on humanitarian supply chains has examined the impact on service delivery \cite{Paul2021}. Studies on the automobile and airline industries have further shown how collaboration patterns shift under crisis conditions \cite{Belhadi2021}. The ripple effect remains a core analytical concept in this body of work \cite{Dolgui2020} and is further linked to robustness and adaptation strategies \cite{Sodhi2021}.

The need for modelling disruption propagation is supported by earlier work on the ripple effect, which formalised how disturbances amplify across supply chains and connected this phenomenon to robustness and viability \cite{IvanovDolguiSokolov2019}. Foundational theoretical work on supply chain disruption modelling had earlier established the conceptual basis for this line of inquiry \cite{Ivanov2017}. Related studies have demonstrated how digital technology and Industry 4.0 reshape ripple dynamics and supply chain risk analytics \cite{Ivanov2019}. However, the literature has also emphasised that predictive power alone is insufficient. Machine-learning-based risk assessment has been shown to trade off performance against interpretability, which creates a governance problem in high-stakes decision contexts \cite{Baryannis2019}.

Industry 4.0 research has added another layer by showing how digital adoption and cyber-physical integration reshape supply chain design \cite{Kamble2018}, a finding extended by subsequent empirical work on Industry 4.0 implementation \cite{Xu2021}. Industry 5.0 perspectives have further emphasised human-centricity as a core design principle \cite{Ivanov2023}. Big data analytics are treated as an enabling capability for supply chain agility \cite{Waller2013}, and predictive analytics have been linked to measurable improvements in performance measurement \cite{Wang2016}. Further studies have demonstrated the role of analytics in supply chain performance \cite{Kache2018}, with dedicated analyses of data-driven capabilities in operational contexts \cite{Dubey2021}. Additional work has examined analytics-enabled supply chain capabilities \cite{FossoWamba2020}, alongside frameworks for measuring performance in digital environments \cite{Frederico2020}. Blockchain has appeared as complementary infrastructure for supply chain transparency \cite{Min2019} and trust in distributed trade networks \cite{Kouhizadeh2021}. Related blockchain applications have targeted sustainability \cite{Dubey2020} and resilience \cite{Queiroz2021}. Additional blockchain frameworks have addressed traceability \cite{Leng2021} and risk mitigation in complex supply networks \cite{Saberi2019}.

The importance of coordination theory is central in this line of work, as agentic and multi-agent systems are fundamentally coordination mechanisms operating under uncertainty \cite{MaloneCrowston1994}.

A parallel line of research has focused on how disruptions propagate through multi-tier networks. Graph-based Monte Carlo methods have been proposed to analyse cascading supply chain shocks across multiple tiers, and graph neural networks have been applied to map supply chain structure and model disruption propagation \cite{KumarDesai2025}. These methods are important because they make network interdependence explicit, which is essential in volatile environments where a local shock can become a system-wide failure.

Enterprise systems are also being reconsidered through this lens. Agentic AI has been described as a force for ERP automation in supply chain management, where cognitive agents are proposed to replace static workflows with autonomous reasoning and execution \cite{Joshi2025}. In planning contexts, agentic AI is presented as a transition from optimisation to autonomous action, shifting the planner's role from system operator to strategic supervisor \cite{Ganesan2025}.

The technical foundations for autonomous supply chains have been established through multi-agent systems (\gls{MAS}) and digital twin research. A systematic review of agent-based modelling and simulation has confirmed that \gls{MAS} has long been applied to the study of decentralised coordination, negotiation, and disruption handling in supply chains \cite{WangZhangLiu2020}. Building on this foundation, autonomous supply chains have been implemented through multi-agent architectures that support monitoring, planning, and negotiation across supply chain tiers \cite{XuEtAl2024}. A digital-twin perspective has further argued that autonomous supply chains are strengthened by coupling agents with a simulation layer, enabling real-time scenario testing and adaptation \cite{XuLuEtAl2024}.

A body of recent literature has positioned agentic AI as a transformative force in supply chain management, shifting the focus from passive prediction to autonomous execution. The integration of real-time inventory management with agentic systems using distributed cloud architectures has been demonstrated, showing that forecasting can be effectively combined with operational action \cite{Tiwari2025}. In retail contexts, agentic AI has been applied for predictive analytics and autonomous customer interaction, particularly where responsiveness and personalisation are essential \cite{Kalisetty2024}. A related study has further demonstrated how supply chain automation in retail benefits from agentic coordination \cite{KalisettySingireddy2023}. Autonomous decision-making has also been extended to food supply chains, where agentic frameworks are proposed as mechanisms for improving control in complex, time-sensitive environments \cite{Pamisetty2024}.

These contributions are aligned with broader reviews of agentic AI that emphasise autonomy, adaptability, tool use, and multi-step goal pursuit as defining paradigm properties of goal-oriented autonomous design \cite{HosseiniSeilani2025}.

The scope of supply chain analytics has been significantly expanded by the recent literature on Large Language Models (\gls{LLM}s), extending it from structured forecasting to unstructured risk interpretation and prescriptive response. A systematic review of LLMs in supply chain management has identified four major application domains: optimisation, risk and security management, knowledge management, and automated contract intelligence \cite{QuHuIvanov2026}. Complementing this synthesis, studies on hyperconnected logistic hubs and crisis response have shown that LLMs can support risk assessment, zero-shot reasoning, and prompt-based logistical reasoning under stress \cite{ZhaoSunLiu2025}.

The most important implication established by this strand of research is that LLMs can help convert event streams, news, and operational text into actionable supply chain intelligence. Broader surveys of agentic AI design confirm that LLMs serve not as isolated chat interfaces but as embedded reasoning components within pipeline architectures connecting language understanding to structured decision workflows \cite{HughesEtAl2025}. This is especially evident in work on automating supply chain disruption monitoring through an agentic AI framework, where specialised agents have been shown to detect events, map impacts across tiers, assess risks, and recommend responses \cite{AlMahriEtAl2026}. The result is a demonstrated transition from descriptive reporting toward near-real-time prescriptive action \cite{AlMahriEtAl2026}.

The sustainability literature shows that agentic and digital systems are increasingly being framed as instruments for aligning efficiency with environmental and social objectives. Agentic AI and ambient intelligence have been proposed together for autonomous sustainability decision-making in supply chains \cite{Tathavadekar2025}. A related framework, SustAI-SCM, has positioned agentic intelligence as a mechanism for automating procurement, logistics, and inventory decisions while explicitly optimising cost and emissions \cite{Aylak2025}. These studies indicate that agentic supply chain design is expanding beyond speed and resilience toward environmental performance and long-horizon optimisation.

Across these streams, the literature has moved from predictive analytics and digital visibility toward agentic autonomy, multi-agent coordination, and prescriptive action. Multi-agent architectures for autonomous supply chains \cite{XuEtAl2024} and agentic systems integrating real-time forecasting with operational action \cite{Tiwari2025} represent the structural and operational foundations of this shift. The application of agentic AI to retail and supply chain automation has further demonstrated the practical breadth of this approach \cite{Kalisetty2024}. Systematic LLM-based analyses have validated these capabilities across multiple supply chain application domains \cite{QuHuIvanov2026}, and specialised agentic disruption monitoring has demonstrated the ability to detect events, map impacts, and recommend responses in real time \cite{AlMahriEtAl2026}. Sustainability-oriented agentic designs have broadened this scope further \cite{Tathavadekar2025}, including explicit optimisation of cost and emissions in logistics workflows \cite{Aylak2025}. Broader reviews have similarly noted that enabling technologies are well-studied while integrated execution frameworks remain absent \cite{White2026}.

The emergence of agentic AI and multi-agent systems represents a significant evolution in supply chain management, moving beyond static predictive modelling toward dynamic, goal-oriented frameworks. By integrating large language models with structured data and symbolic reasoning, these systems can automate complex decision-making processes, bridging the gap between high-level analytical insights and concrete operational execution. Recent advancements in agentic orchestration enable specialised roles to be assigned for monitoring, optimising, and reporting, which provides a cohesive, scalable approach to managing logistics friction in volatile, high-stakes trade environments. This hybrid approach, combining the reasoning capabilities of LLMs with structured pathfinding and mathematical optimisation, serves as the foundation for the proposed digital twin, ensuring that autonomous responses remain both intelligent and explainable.

\section[Methodology and Architectural Roadmap]{\textbf{Methodology and Architectural Roadmap}}
The methodology for this project is structured into five distinct phases, transitioning from network modeling to autonomous execution and validation.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.65\textwidth]{Figures/methodology}
    \caption{Proposed methodology}
    \label{fig:methodology}
\end{figure}

\begin{itemize}
    \item \textbf{Phase 1: Network Model Construction \& Baseline Development:} Develop a multi-tier logistics graph using \texttt{NetworkX}, mapping critical nodes from international maritime chokepoints (e.g., Mundra, Dubai) to inland Indian SME clusters. Simultaneously, establish a Manual Human Planner baseline using Chopra inventory formulas to provide a performance benchmark for traditional, reactive supply chain management.
    \item \textbf{Phase 2: Multi-Agent Orchestration (Intelligence Layer):} Design and deploy specialized autonomous agents using \texttt{LangChain} and \texttt{CrewAI}. This includes a Friction Sentry for real-time monitoring of maritime signals (e.g., verification delays, insurance spikes, or congestion) and a Logistics Optimizer for executing autonomous rerouting and dynamic buffer-stock calculations.
    \item \textbf{Phase 3: Stress-Testing \& Friction Propagation:} Inject 1 simulated Friction Shock---ranging from administrative bottlenecks to regional blockades---into the graph model. The agents will identify these disruption signals, propagate the impact across the multi-tier supply chain, and evaluate the mathematical trade-offs of various mitigation strategies.
    \item \textbf{Phase 4: Autonomous Mitigation \& Execution:} The agentic pipeline autonomously selects the most efficient recovery path, such as pivoting to multimodal transport or identifying backup suppliers, to minimize Total Landed Cost and operational downtime. This phase transitions the system from simple "Detection" to "Executable Action".
    \item \textbf{Phase 5: Visualization \& Performance Validation:} Integrate the agentic output into an interactive Dashboard for real-time decision support. Validate the framework's effectiveness by comparing its response latency and cost-efficiency against the previously established manual baseline, targeting a measurable reduction in stockouts and overstocking.
\end{itemize}
